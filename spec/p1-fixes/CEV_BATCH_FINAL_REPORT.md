## 1. 摘要

CEV 解析定价（Schroder 1989 非中心卡方公式）存在**非中心卡方自由度错配**：旧实现 ν₁ = 2/(1−β)、ν₂ = 2/(1−β)−2，正确值为 **ν₁ = 2+1/(1−β)、ν₂ = 1/(1−β)**。两套自由度**仅在 β=0.5 重合**——历史测试全绿、以及「β=0.5 对 MC 一致」的验证恰好落在不动点上；实际 **β≠0.5 全域定价错误**（β<0.5 可低于内在价值，β=0.3/σ=4/K=100 偏高 66%，β=0.7 偏高 40%）。

专项批按「批 A 公式修正 + 批 B 数值层加固 + 测试重定基」完整实施并闭环：本地 Release 全量 **2643/2643**，CI 两次 **10/10**。同时修正了上一批「仅 β<0.5 失效」的范围判断。

## 3. 根因

### 3.1 D-1 自由度错配（P0）

本库 SDE：`dS = (r−q)S dt + σ S^β dW`；Schroder 1989 原文采用 `dS = μS dt + σ S^{β_S/2} dW`，即 **β_S = 2β**。

| 量 | Schroder 原文 | 本库换算 | 旧实现 | 是否一致 |
|---|---|---|---|---|
| 第一项自由度 ν₁ | 2 + 2/(2−β_S) | **2 + 1/(1−β)** | 2/(1−β) | ❌ 仅 β=0.5 相等 |
| 第二项自由度 ν₂ | 2/(2−β_S) | **1/(1−β)** | 2/(1−β) − 2 | ❌ 仅 β=0.5 相等 |
| c/d 缩放 | 含 r−q 指数式 | 与代码一致 | 一致 | ✅ |

两层独立证据：

1. **β=0 极限自检**：吸收壁 Bachelier 应为 ν₁=3、ν₂=1；旧实现 ν₂=0 直接触发 `noncentral_chi2_cdf: k must be positive` 异常。
2. **不动点解释**：β=0.5 时 2/(1−β) = 2+1/(1−β) = 4、2/(1−β)−2 = 1/(1−β) = 2，新旧公式完全重合。

### 3.2 D-2 数值层（P2）

- `noncentral_chi2_cdf` 大 λ 分支固定 5σ Poisson 窗口 → CDF 绝对误差 ~1e-7；
- `P₁ = 1 − CDF` 在深 OTM 暴露该误差 → **P1 地板 3.17e-7、价格地板 3.17e-5**；
- 深 ITM 绝对偏差 1–3e-5。

**关键实现点**

- `detail::ncchi2_mixture(x, k, λ, upper)`：小 λ（≤50）直接 Poisson 级数；大 λ 对数空间权重，窗口 = Poisson ±10σ ∪ `j_hi_gamma = x/2 + 10√(x/2)`（因为 Q(a, x/2) 的峰值在 a≈x/2，可能远离 Poisson 众数）。
- `noncentral_chi2_sf`：上尾直算，消除 `1−CDF` 抵消。
- CEV：`P₁ = noncentral_chi2_sf(c, ν₁, d)`、`P₂ = noncentral_chi2_cdf(d, ν₂, c)`；不做价格钳位。

## 9. 教训

1. **单一参数点与参照一致，不能证明实现正确**——自由度/系数类错误可能恰好在该点抵消；绝对锚必须覆盖参数全域（含 β=0、β=1 边界）。
2. **上尾混合的求和窗口不能只按 Poisson 主体截取**——Gamma 因子 Q(a, x/2) 的峰值在 a≈x/2，可能远离 Poisson 众数，窗口必须按因子有效区扩展。
3. **结构断言背后可能藏着 1e-5 级数值误差**（IV 翼、校准形状）；绝对精度锚（如深 ITM |C−内在|<1e-10）比相对容差更能锁住性质。
4. **「范围判断」也要证据**：上批「仅 β<0.5」源于只在 β=0.3 与 0.5 两个点对照；参数扫描（β 全域 + 1/β→1 边界）是族类缺陷的必要步骤。
