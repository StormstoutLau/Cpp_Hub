## §1 当前实现与公式结构

[cev_analytic.hpp](../../include/cpphub/pricing/analytic/cev_analytic.hpp)（β<1 分支）：

```
c = 2(r−q)K^{2(1−β)} / (σ²(1−β)(e^{2(r−q)(1−β)T}−1))      // r=q 时取极限 c=K^{2(1−β)}/(σ²(1−β)²T)
d = 2(r−q)S^{2(1−β)}e^{2(r−q)(1−β)T} / (σ²(1−β)(e^{2(r−q)(1−β)T}−1))
ν₁ = 2/(1−β),  ν₂ = 2/(1−β) − 2 = 2β/(1−β)
P₁ = 1 − χ'²(c; ν₁, d)
P₂ = χ'²(d; ν₂, c)
C = S e^{−qT} P₁ − K e^{−rT} P₂
```

c/d 缩放本身是**正确**的（§3 数值验证），错的是 ν₁/ν₂。

## §2 文献公式与换算

本库约定：`dS = (r−q)S dt + σ S^β dW`。Schroder (1989) / Cox (1975) 原文采用 `dS = μS dt + σ S^{β_S/2} dW`，即 **β_S = 2β**。

**Schroder 1989 原文（A 级引文，sci-hub PDF 摘录）**：

> "The integrands are both noncentral chi-square density functions. The first is p[2w; 2+2/(2−β), 2x], with **2+2/(2−β) degrees of freedom** and noncentral parameter 2x. Integrating with respect to w from y to infinity gives the corresponding complementary distribution function Q[2y; 2+2/(2−β), ...]"

**TKU 讲义（A 级，公式重述）**：

> C_t = S_t Q(2K′; 2+2/(2−β), 2S′) − e^{−rt}K[1 − Q(2S′; 2/(2−β), 2K′)]

换算到本库 β（β_S = 2β）：

| 量 | Schroder/讲义 | 本库换算 | 当前代码 | 是否一致 |
|---|---|---|---|---|
| 第一项自由度 ν₁ | 2 + 2/(2−β_S) | **2 + 1/(1−β)** | 2/(1−β) | ❌ 仅 β=0.5 相等 |
| 第二项自由度 ν₂ | 2/(2−β_S) | **1/(1−β)** | 2/(1−β) − 2 | ❌ 仅 β=0.5 相等 |
| 求值点 / 非中心参数 | 2K′ / 2S′ | c / d（代码同） | c / d | ✅ |
| c/d 缩放 | 含 r−q 的指数式 | 与代码一致 | 一致 | ✅ |

**β=0 极限自检**（不用文献也能判断）：β=0 时过程为 `dS = (r−q)S dt + σ dW`（吸收壁在 0），是两个自由度分别为 3 和 1 的非中心卡方组合——正确公式给 ν₁=3、ν₂=1；当前公式给 ν₁=2、ν₂=0，`noncentral_chi2_cdf` 因 `k must be positive` 直接抛异常。这独立证明自由度写错。

## §3 本地实证（A 级，可复现）

复现脚本见附录 A。核心结果：

### 3.1 硬锚：β=0 吸收壁 Bachelier 闭式

`S=100, K=80, σ=4, T=1, r=q=0`：

- 吸收壁 Bachelier 闭式（反射原理）：`C = (S−K)Φ((S−K)/s) + sφ((S−K)/s) − sφ((S+K)/s) + (S+K)(1−Φ((S+K)/s))`，`s=σ√T`
- 闭式值 **20.0000002138**；修正公式 **20.0000002138**（差 **8.5e-14**）
- 当前公式：ν₂=0 → `noncentral_chi2_cdf` 抛异常（scipy 端表现为 -inf）

### 3.2 β=0.5 不动点

任意 10 组随机参数（σ∈[0.1,2], K∈[50,200], r,q∈[0,0.08]）下新旧公式**逐位相等**（diff 0.00e+00）——两套自由度在 β=0.5 重合，历史「β=0.5 对 MC 一致」的验证因此具有误导性。

### 3.3 Monte Carlo（独立于解析公式）

| 0.3 | 4.0 | 100 | 0/0 | 3.8122 | **6.3494** | 6.3199±0.0301 | 2.508 | 0.030 |

### 3.4 无套利界

525 点网格（β∈{0.05,0.2,0.35,0.5,0.65,0.8,0.95} × σ∈{0.2,0.5,1,2,4} × K∈{50,80,100,120,200} × (r,q)∈{(0,0),(.05,.02),(.02,.05)}）：

- 下界 `S e^{−qT} − K e^{−rT} ≤ C ≤ S e^{−qT}`
- 修正公式：**0/525 违反**
- 当前公式：β<0.5 且宽跨式参数下违反（如 β=0.3, σ=4, K=80 → 19.7271 < 20）

### 3.5 β→1 奇异极限（B 级）

β→1 时非中心卡方表示退化（df→∞、非中心参数→∞），scipy 在 β≥0.99999 出现级数不收敛；β=0.9999 与 BS 仍差 3.5e-3（线性于 1−β）。这是公式表示的**病态极限**，不是新缺陷；现有 `|β−1|<1e-10 → BS` 特判必须保留，不建议以 β→1 作为数值锚。

## §4 数值层 D-2（同一函数内的独立问题）

[math.hpp](../../include/cpphub/core/math.hpp) `noncentral_chi2_cdf` 大 λ 分支：

```
j ∈ [λ/2 − 5√(λ/2), λ/2 + 5√(λ/2) + 10]   // 固定 5σ Poisson 窗口
```

- Poisson 尾部截断 → CDF 绝对误差 ~1e-7（与参数有关，实测 3.17e-7）
- `P₁ = 1 − CDF` 在深 OTM 直接暴露该误差 → **P1 地板 3.17e-7、价格地板 3.17e-5**

修正自由度后仍存在的数值层偏差（C++ 数值复刻 vs scipy 高精度参考）：

| 区域 | 参数 | 参考价 | 当前数值层 | 偏差 |
|---|---|---|---|---|
| 深 ITM | β=0.5, σ=0.3, K=80 | 20.0000000000 | 20.0000224641 | 2.2e-5 |
| 深 ITM | β=0.3, σ=0.3, K=80 | 20.0000000000 | 20.0000302564 | 3.0e-5 |
| 深 OTM | β=0.5, σ=0.3, K=120 | 4.6652e-11 | 3.1674e-5 | 地板 |
| 深 OTM | β=0.5, σ=0.3, K=130 | 1.5402e-21 | 3.1673e-5 | 地板 |
| 深 OTM | β=0.5, σ=0.3, K=150 | 1.0416e-51 | 3.1673e-5 | 地板 |
| 中尾 | β=0.7, σ=0.3, K=120 | 1.6758e-02 | 1.6784e-02 | 2.6e-5 |

**结论**：D-2 不改变「主价正确性」（中尾影响 ~1e-5），但深 OTM 翼的相对误差完全失真，直接影响 CEV 隐含波动率翼与校准形状（与 `RESEARCH_ONEMPHI_SWEEP` §4.3 的 P1 地板结论同源）。修复需要：

1. 新增 `noncentral_chi2_sf(x, k, λ)`（上尾直接累加 Poisson 混合的 `regularized_upper_gamma`）；
2. 求和窗口按**相对项**自适应（不能只用 Poisson 5σ 窗口——深 OTM 的 SF 由窗口外 j 主导）；
3. `P₁ = noncentral_chi2_sf(c, ν₁, d)`，消除 `1−CDF` 抵消；
4. P₂ 仍用 CDF，但大 λ 窗口需加宽到足以保证深 ITM 绝对精度（建议按相对项停止准则统一重写大 λ 分支）。

性能预算：CEV 标定器在 DE 中会做 ~10^4–10^5 次定价调用；窗口加宽会放慢。实施时需给出基准（基线 `BoundaryBetaNoCrash` 57.7s）并设上限（建议 ≤2×）；优先用相对项停止而非固定倍宽。

## 附录 A 自足复现（Python 3.12 + scipy/mpmath）

```python
import math
from scipy.stats import ncx2, norm

def cev_cd(beta, sigma, S, K, T, r, q):
    omb = 1.0 - beta; tw = 2.0*omb; drift = r - q
    if abs(drift) < 1e-12:
        den = sigma*sigma*omb*omb*T
        c = K**tw/den; d = S**tw/den
    else:
        arg = 2.0*omb*drift*T
        den = sigma*sigma*omb*math.expm1(arg)
        c = 2.0*drift*K**tw/den
        d = 2.0*drift*S**tw*math.exp(arg)/den
    return c, d

def cev_price(beta, sigma, S, K, T=1.0, r=0.0, q=0.0, fixed=True):
    omb = 1.0 - beta; c, d = cev_cd(beta, sigma, S, K, T, r, q)
    nu1 = (2.0 + 1.0/omb) if fixed else (2.0/omb)
    nu2 = (1.0/omb) if fixed else (2.0/omb - 2.0)
    P1 = ncx2.sf(c, nu1, d)
    P2 = ncx2.cdf(d, nu2, c)
    return S*math.exp(-q*T)*P1 - K*math.exp(-r*T)*P2

# 关键案例: 19.7271170163 (old) vs 20.7042140 (fixed), MC 20.6433 +/- 0.0465
print(cev_price(0.3, 4.0, 100, 80, fixed=False), cev_price(0.3, 4.0, 100, 80))

# beta=0 硬锚
s = 4.0
exact = ((100-80)*norm.cdf((100-80)/s) + s*norm.pdf((100-80)/s)
         - s*norm.pdf((100+80)/s) + (100+80)*(1-norm.cdf((100+80)/s)))
print(exact, cev_price(0.0, s, 100, 80))   # 20.0000002138 二者一致
```

MC 复现：Euler + 吸收壁，100k 路径、16000 步、`numpy.random.default_rng(seed)`；见调研期 tmp 脚本逻辑（`S += μS dt + σ S^β √dt Z; S=max(S,0)`）。
